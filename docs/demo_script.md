# Model Doctor — Demo Script

1. Open the React static demo.
2. Explain that each selectable model comes from the controlled 100-model zoo.
3. Select a model.
4. Show the predicted diagnosis and confidence.
5. Open the probability distribution and explain that the Random Forest produced it.
6. Show the ten diagnostic features.
7. Explain one or two features relevant to the displayed diagnosis.
8. Show the Grad-CAM image and corner-attention value.
9. Show the fixed suggested fix.
10. Reveal the experimental ground truth only as an evaluation reference.
11. Select another fault type and repeat.
12. If asked about model performance, open `reports/metrics.json` and report only the recorded values.
